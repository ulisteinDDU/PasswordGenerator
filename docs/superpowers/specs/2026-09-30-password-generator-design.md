# 随机密码生成器 — 设计规格

- 日期: 2026-09-30
- 状态: 已确认（待实现）
- 平台: Windows 10 及以上
- 语言: 纯 C（Win32 原生 API）

## 1. 目标

用纯 C 编写一个 Windows 可视化随机密码生成器，编译为可双击运行的 `.exe`，源码保留。

## 2. 需求

- GUI 界面，双击即用，无控制台黑框（GUI 子系统）。
- 默认密码长度 8；可调，范围 **4–32**。
- 默认字符集：数字 + 小写字母 + 大写字母。
- 特殊字符可选（默认关闭）。
- 复制到剪贴板按钮。
- 排除易混淆字符（`0 O 1 l I`）选项（默认关闭）。
- 界面简洁。

## 3. 非目标（YAGNI，均不做）

密码强度评估、密码历史、批量生成、配置持久化（记住上次设置）、多语言/国际化、安装程序。

## 4. 架构

单文件 C 程序，使用 Win32 原生 API（`CreateWindowEx` + 注册窗口类 + 消息循环）。无外部依赖，仅链接系统库。

### 文件内逻辑分区（职责单一）

1. **随机数** `gen_random_bytes(buf, n)`：封装 `BCryptGenRandom`，提供密码学安全随机字节。
2. **字符集** `build_charset(...)`：根据勾选项构建候选字符池（动态拼接）。
3. **生成** `generate_password(...)`：从池中按长度均匀抽取，每位独立均匀分布。
4. **剪贴板** `copy_to_clipboard(hwnd, text)`：`OpenClipboard/EmptyClipboard/SetClipboardData`。
5. **UI**：窗口、控件创建、`WM_COMMAND` 处理、布局。

## 5. 界面（简洁）

```
┌──────────────────────────────────────────┐
│  随机密码生成器                           │
├──────────────────────────────────────────┤
│  密码长度: [  8  ] ▲▼        (4 ~ 32)    │
│                                          │
│  ☑ 数字 (0-9)     ☑ 小写字母 (a-z)       │
│  ☑ 大写字母 (A-Z) ☐ 特殊字符 (!@#... )   │
│  ☐ 排除易混淆字符 (0 O 1 l I)            │
│                                          │
│  ┌────────────────────────────┐  [ 复制 ]│
│  │  xY7$kP2q                  │          │
│  └────────────────────────────┘          │
│                                          │
│             [   生成密码   ]              │
└──────────────────────────────────────────┘
```

控件：长度 spinbox（4–32，默认 8）；4 个字符集复选框（前三默认勾选）；1 个排除易混淆复选框（默认不勾）；只读等宽显示框；生成、复制按钮。

## 6. 安全

- 使用 `BCryptGenRandom`（Win10+ 系统级 CSPRNG），**不使用** `rand()`。
- 链接 `-lbcrypt`。

## 7. 构建与产物

- 编译器：便携版 MinGW-w64 GCC，下载到 `tools/mingw64/`，不写入系统环境变量，可整体删除。
- 编译命令：
  `gcc -O2 -mwindows -o PasswordGenerator.exe src\password_generator.c -lbcrypt`
  - `-mwindows` → GUI 子系统，双击不弹黑框。
- `build.bat`：一键构建。
- 产物：`PasswordGenerator.exe`（双击即用）。

## 9. 错误处理

- 未勾选任何字符集 → `MessageBox` 提示，不生成。
- 长度越界 → 钳制到 `[4, 32]`。
- 剪贴板打开/写入失败 → 提示复制失败。
- `BCryptGenRandom` 失败 → 提示生成失败。

## 10. 测试

- 构建成功，双击启动无黑框。
- 手动验证：
  - 默认生成 8 位，含数字 + 大小写字母。
  - 勾选特殊字符后含特殊字符；取消则不含。
  - 长度可调（4 与 32 边界）。
  - 复制按钮可用，粘贴结果一致。
  - 排除易混淆字符生效（不含 0/O/1/l/I）。
  - 全部取消勾选时弹窗提示且不生成。
