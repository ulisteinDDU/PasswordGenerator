# 密码生成器增强 — 256 位长度 / 图标 / 可缩放 / 交互优化 设计规格

- 日期: 2026-10-05
- 状态: 已确认（待实现）
- 前置: 基于 2026-09-30 已实现的随机密码生成器（`src/password_generator.c`）
- 平台: Windows 10 及以上；语言: 纯 C（Win32 原生 API），零新依赖

## 1. 目标

在既有单文件纯 C 密码生成器上完成四项增强：

1. 密钥长度上限从 32 字符扩展到 **256 字符**
2. 应用**图标**（资源管理器 / 标题栏 / 任务栏 / Alt-Tab 一致）
3. 窗口**可缩放**（拖边、最大化），默认尺寸适当加大
4. **交互优化**：强度/熵显示、长度快捷档位、选项变更自动重新生成、每种勾选字符至少含一个

## 2. 需求细节

### 2.1 长度与档位
- 长度范围 **4–256 字符**，默认 **16**（启动即生成）。
- 长度输入：数值框 + spin（UDM_SETRANGE32 4~256）。
- 快捷档位按钮 6 个：`8 / 16 / 32 / 64 / 128 / 256`，点击即设置长度并重新生成。

### 2.2 生成逻辑（每类至少一个）
- 先从每个勾选集合（经"排除易混淆"过滤后）各抽 1 个字符；
- 剩余位从全池均匀抽取（沿用无偏拒绝采样 `unbiased_index`）；
- 最后用 CSPRNG（BCryptGenRandom）做 **Fisher–Yates 洗牌**，消除"集合字符固定出现在前几位"的位置规律。
- 边界论证：MIN_LEN=4 ≥ 最多 4 个勾选集合，恒可满足；任一集合过滤后最少剩 8 个字符（数字集剔 0/1 后），不会为空。
- 熵估算：`log2(池大小) × 长度`（bit，保留 1 位小数）。

### 2.3 强度显示
- 自绘强度条子窗口（注册独立窗口类，`WM_PAINT` 绘制圆角条）+ 文本标签。
- 分档与配色（近似 Windows 系统色）：
  - `< 40 bit` 弱 · 红 `#E81123`
  - `< 60 bit` 中 · 橙 `#FF8C00`
  - `< 128 bit` 强 · 蓝 `#0078D7`
  - `≥ 128 bit` 极强 · 绿 `#107C10`
- 条填充比例 = `min(1, bits / 128)` 线性映射；文本形如 `熵 ≈ 103.3 bit · 强`。

### 2.4 窗口与缩放布局
- 窗口样式：现样式 + `WS_THICKFRAME | WS_MAXIMIZEBOX`（拖边缩放、最大化）。
- 默认尺寸 **640×440**（客户区按 DPI 缩放）；`WM_GETMINMAXINFO` 钳制最小 **560×360**。
- 锚点表布局：小型布局规则表（控件句柄 + 锚定标志），`WM_SIZE` 时统一 `MoveWindow`：
  - 顶部：长度行 + 6 个档位按钮（随宽横向拉伸间距）
  - 其下：字符集复选框 2×2 + 排除易混淆复选框（锚定左上）
  - 中部：**密码显示框为弹性区域**（随窗口宽高增长；多行只读 `ES_MULTILINE | WS_VSCROLL`，自动换行，256 字符完整可读）
  - 密码框下：强度条 + 熵值文本（随宽拉伸）
  - 底部：生成 / 复制按钮（锚定底部）
- DPI：`app.manifest` 声明 `PerMonitorV2`；`WM_DPICHANGED` 时按新 DPI 重建字体、按建议矩形调整窗口、重排布局。高分屏（150%/200%）不模糊。

### 2.5 图标
- 新增 `tools/make_icon.py`（Pillow；若环境无 Pillow 则用 PowerShell System.Drawing 兜底）：
  深蓝→青紫渐变圆角方块 + 白色粗钥匙图形，多尺寸 16/24/32/48/64/128/256 打包 `app.ico`。
- `app.ico` 产物入库；脚本仅供日后重新生成。
- `app.rc` 增加 `1 ICON "app.ico"`（exe 文件图标）；窗口类 `hIcon/hIconSm` 加载同一资源（标题栏/任务栏/Alt-Tab）。

### 2.6 交互优化
- 任一复选框勾选变化、spin 增减、档位按钮、长度框 EN_CHANGE → **自动重新生成**并更新强度显示（生成开销微秒级，不做防抖）。
- 保留「生成密码」按钮（手动换一个）；「复制」逻辑不变。
- 键盘 Tab 导航沿用 `IsDialogMessageW`。

## 3. 非目标（YAGNI）

密码历史、批量生成、配置持久化、多语言、安装程序、密码记忆化加密存储、深色模式。

## 4. 架构

维持**单文件** `src/password_generator.c` + 文件内分区（随机数 / 字符集 / 生成 / 剪贴板 / 布局 / UI），新增：

| 单元 | 职责 |
|------|------|
| 布局助手 | 锚点规则表 + `layout_controls()`，供 `WM_CREATE` / `WM_SIZE` / `WM_DPICHANGED` 调用 |
| 强度条控件 | 独立窗口类 `CrtStrengthBar`，接收熵值消息自绘 |
| 洗牌生成 | `generate_password` 扩展：各类保底 1 字符 + Fisher–Yates |
| 熵计算 | `estimate_entropy_bits(poolLen, length)` → double |

## 5. 错误处理

- 沿用现状：未勾选任何集合 → 弹窗提示；长度越界 → 钳制；CSPRNG 失败 → 弹窗。
- 洗牌与保底抽取同样依赖 `unbiased_index`，失败即整体判为生成失败。

## 6. 构建与产物

- `build.bat` 命令不变（windres 自然纳入 app.ico）。
- 产物仍为单 `PasswordGenerator.exe`。
- 新增文件：`tools/make_icon.py`、`app.ico`；修改：`src/password_generator.c`、`app.rc`、`app.manifest`、`README.md`。

## 7. 测试（手动清单）

1. 256 长度生成、显示（换行/滚动）、复制粘贴完整一致。
2. 每种勾选字符至少出现一个（多次抽样验证，含"排除易混淆"组合）。
3. 拖边缩放、最大化、还原、最小尺寸 560×360 下布局不重叠不残留。
4. 档位按钮设置正确长度并重生成；spin/输入框/复选框变化即时重生成、强度条与熵值同步。
5. 强度分档颜色与文本随选项变化正确（构造弱/中/强/极强四种组合）。
6. 图标：资源管理器 .exe、标题栏、任务栏、Alt-Tab 四处一致显示。
7. 系统 DPI 150%/200% 下文字与控件清晰、无裁剪；跨屏拖动（不同 DPI）不乱版。
8. 全部取消勾选 → 弹窗且不崩溃；CSPRNG 不可用路径（代码审查）。
